# The First 24 Hours of a Crypto Theft

<span style={{ fontFamily: 'var(--font-space-mono), monospace', fontSize: 13, opacity: 0.7 }}>`checklist`</span>

## Core idea
The target is a freezing order and preservation notices inside 24 hours of discovery. That deadline is set by how fast the money moves, not by how fast the analysis can be finished, so the first day runs on partial information by design. Waiting for a complete trace before filing is a recognised way to lose the funds.

## Components
**First 60 minutes, the six questions:**
- When was the theft discovered, and when did it most likely occur? These are different times, and the gap matters.
- What is the estimated amount and asset type?
- Have the assets already moved from the initial destination?
- What security mechanism was compromised?
- Are private keys or credentials still exposed right now?
- Is an insider plausible?

**Capture immediately:**
- Screenshots of the transactions and wallet interfaces.
- Access logs covering the relevant window.
- Any correspondence with the attacker.
- Transaction hashes and every wallet address involved, recorded in full.
- The internal security assessment.

**Technical actions inside the first hours:**
- Stand up real-time monitoring and automated movement alerts on every identified address.
- Commission an initial forensic trace, accepting that it will be provisional.
- Assess velocity: rapid splitting behaves differently from dormant holding and changes the filing urgency.
- Check for cross-chain bridge use early, because it widens the jurisdictions you need to cover.
- Mirror affected systems and preserve logs under chain of custody.

**Legal actions inside the 24-hour window:**
- Select jurisdictions on four inputs: where the known exchanges sit, where the victim is domiciled, where the suspects are believed to be, and which legal systems already have crypto jurisprudence.
- Decide order scope: worldwide versus jurisdiction-specific, asset classes named, duration and renewal, and which intermediaries must be notified.
- File ex parte freeze applications, freezing injunctions, or temporary restraining orders with asset freeze provisions.
- File police reports in the relevant jurisdictions even where no immediate action is expected, because the report number is often a prerequisite later.

## When to use
The moment a live theft is reported and recovery is on the table.

## Avoid when
Do not run this drill on a cold case. Where the funds moved months ago and have already been cashed out, the 24-hour posture spends money on speed that no longer buys anything, and the case belongs in a standard investigation arc instead.
